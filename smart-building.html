Smart Building Energy Forecasting

Behavioral vs Climate Load Drivers: Analyzing weather's impact on residential appliance energy consumption

Project Overview

This project analyzes how outdoor weather (temperature, humidity) relates to appliance-level energy consumption in a residential building, answering a key smart-city question: Can we reliably forecast appliance energy demand using only weather data?

Residential Building Data

UCI Machine Learning Repository dataset with 10-minute resolution measurements

SQL + Python Analysis

Multi-table data modeling with SQLite, comprehensive EDA, and statistical analysis

Power BI Dashboard

Interactive dashboard with KPIs, trend analysis, and conditional formatting

Key Findings

Critical Discovery: Behavior Trumps Climate

Weather explains almost none of the variation in appliance energy consumption. This finding has major implications for smart building optimization strategies.

Conclusion & Future Work

Key Takeaway:

Appliance energy usage is behavior-driven, not climate-driven. Weather-based forecasting for this load type is ineffective. Smart building optimization should prioritize:

  • Occupancy patterns and scheduling
  • Device-level automation and smart controls
  • Behavioral interventions rather than climate adjustments

Future Extensions:

  • Add calendar & occupancy features
  • Separate appliance vs HVAC loads
  • Non-linear models (Random Forest, XGBoost)
  • Interactive Streamlit web app
