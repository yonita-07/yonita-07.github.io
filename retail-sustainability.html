Retail Sales & Sustainability Performance Analysis

Leveraging data science to drive sustainability-focused decision making in modern retail businesses

Project Overview

This comprehensive project combines synthetic data generation, exploratory data analysis, feature engineering, and interactive Power BI dashboards to evaluate revenue, emissions, waste, and product returns in retail environments.

Synthetic Data Generation

Realistic retail transaction data with category-specific pricing, waste, and emission factors

Exploratory Analysis

In-depth EDA with distribution analysis, correlations, and category-wise comparisons

Power BI Dashboard

Interactive visualizations with category-wise KPIs and actionable insights

Key Features

1. Synthetic Data Generation (Python)

  • Creates realistic retail transaction data
  • Category-specific pricing, waste, return rates, and emission factors
  • Computes comprehensive sustainability metrics

Sustainability Metrics:

• Total Emissions • Emission per Unit • Sustainability Index • Waste Contribution • Revenue Impact

2. Exploratory Data Analysis

  • Distribution analysis of revenue, waste, returns, and emissions
  • Category-wise performance comparison
  • Correlation heatmaps and environmental impact insights

3. Power BI Dashboard

Interactive dashboard with comprehensive category-wise insights:

KPI Cards

  • • Total Revenue
  • • Total Emissions
  • • Total Waste
  • • Return Rate
  • • Sustainability Index

Interactive Elements

  • • Category slicers
  • • Product filters
  • • Dynamic visuals
  • • Drill-down capabilities

Visualizations

  • • Scatter plots
  • • Bar charts
  • • Comparison views
  • • Trend analysis

Key Insights from Dashboard

Category-wise performance analysis revealing sustainability opportunities

Electronics

Highest revenue generator but also produces high emissions - optimization opportunity

Beauty

Lowest revenue but nearly zero waste & returns - sustainability champion

Home

Most balanced performance across all metrics - ideal benchmark

Sports

High sales volume but highest emissions - requires intervention

Clothing

Moderate revenue with moderate environmental impact - stable category

Actionable Insight

Focus on reducing emissions in Electronics & Sports while maintaining revenue growth

Technologies Used

Python Pandas NumPy Matplotlib Seaborn Jupyter Notebook Power BI Git / GitHub

Conclusion

This project demonstrates how data science can quantify retail sustainability and visualize key metrics for informed decision-making. By integrating Python analysis with Power BI visualization, the workflow becomes both analytically robust and business-friendly.
